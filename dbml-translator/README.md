# dbml-translator

> DBML 스키마를 비개발자에게 설명하고, 기획서와의 빈틈을 짚고, Mermaid ERD로 렌더링하는 세 스킬 패키지.

- Version: `0.2.0`
- License: MIT
- Author: 정인권 (`developjik@colosseum.kr`)
- plugin-eval (정적): plugin 100/100, 각 skill 100/100, fail/warn 0건 (budget moderate)

## Skills

| 스킬 | 트리거 | 입력 | 산출물 |
|---|---|---|---|
| `dbml-explain` | `.dbml` 파일/코드블록이 대화에 등장, "이 스키마 설명해줘", "PM에게 DB 설명", "비개발자 설명" 같은 요청 | DBML 텍스트 (SQL DDL 아님) | 한 줄 요약 → 핵심 엔티티 → 관계 → enum → 시나리오 예시 → 누락/모호 지점 |
| `dbml-spec-diff` | DBML + PRD/기획서 둘 다 대화에 존재, "기획서랑 DBML 다른 부분", "스펙대로 됐는지", "find gaps PRD schema" | DBML 텍스트 + 기획 문서 | 커버리지 매트릭스 → 누락 → 초과 → 의미 불일치 → cardinality 충돌 → P0/P1/P2 Top 3 |
| `dbml-to-mermaid` | DBML이 있고 "ERD 그려줘", "mermaid로", "Confluence에 붙일 다이어그램", planning-publish 직전 그림 필요 | DBML 텍스트 (+ 선택: TableGroup) | Mermaid `erDiagram` fenced 블록 → 한국어 캡션 → 임베드 가이드 → 손실/주의 항목 |

스킬 자체 본문은 각 `skills/<name>/SKILL.md`에 있고, 트리거 description은 plugin-eval baseline에 맞춰 짧게 유지합니다.

## 사용 예시

Claude Code:

```text
/dbml-translator:dbml-explain
/dbml-translator:dbml-spec-diff
/dbml-translator:dbml-to-mermaid
```

Codex:

```text
$dbml-explain
$dbml-spec-diff
$dbml-to-mermaid
```

## Install

Claude Code:

```bash
claude plugin marketplace add https://github.com/inkwonjung-colosseum/plugins
claude plugin install dbml-translator@inkwonjung-colosseum
```

Codex App: 앱의 `/plugins` 화면에서 marketplace를 추가한 뒤 dbml-translator를 활성화합니다.

## 검증

```bash
claude plugin validate ./
plugin-eval analyze ./ --format markdown
plugin-eval analyze ./skills/dbml-explain --format markdown
plugin-eval analyze ./skills/dbml-spec-diff --format markdown
plugin-eval analyze ./skills/dbml-to-mermaid --format markdown
```

벤치마크 템플릿은 `.plugin-eval/benchmark.json`에 있습니다. 실 codex 실행 기반이므로 scenario를 도메인 데이터로 바꿔 사용합니다.

```bash
plugin-eval benchmark ./ --config ./.plugin-eval/benchmark.json --format markdown
```

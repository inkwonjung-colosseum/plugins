# humanize-korean — 출력 계약 (단계 5에서 Read)

윤문본을 산출한 뒤 이 파일을 적재해 출력·요약·등급·후속을 처리한다. 탐지·윤문(단계 2–3)에는 필요 없다.

## 출력 위치

- 짧은 글: 응답에 마크다운 블록으로 직접 출력.
- 긴 글이거나 파일 입력: 원본 옆에 `<원본명>.humanized.md`로 저장(사용자 지정 경로 우선).
- 본문 끝에 아래 요약 블록을 정확히 1개 붙인다.

## 출력 요약 포맷

윤문본 본문 직후 빈 줄 한 줄을 두고 아래 HTML 주석 블록을 정확히 1개 추가한다. (마크다운 뷰어·게시·복사 시 본문에 노출되지 않는다. `grep "HUMANIZE-SUMMARY"`로 추출.)

```markdown
{윤문본 본문 그대로}

<!-- HUMANIZE-SUMMARY
metrics:
  char_in: 2604
  char_out: 2210
  change_rate: 15.1%
  self_check: 6/6
  grade: A
categories:        # before → after, quick-rules ID 기준
  D-4 hype 어휘: 5 → 0
  H-3 메타 진입: 6 → 1
  C-11 연결어미 뒤 쉼표: 9 → 0
self_check:
  - 고유명사·수치·인용 100% 보존: ✅
  - 변경률 30% 이하: ✅
  - 장르 이탈 없음: ✅
  - register 보존: ✅
  - S1 잔존 0건: ✅
  - 인공 표현 추가 없음: ✅
highlights:        # 3~5건, 각 100자 이내
  - id: D-6
    before: "지금이야말로 ~ 진지하게 고민할 때다."
    after: "~ 짚을 차례다."
residual_findings: (없음 / ID + 사유)
grade_reason: "A — S1 0건, 변경률 15.1%, 자체검증 6항 통과. 칼럼 register 그대로."
-->
```

## 응답 형식 (사용자에게 직접)

1. 한 줄 상태: `완료. 변경률 X% / 등급 Y / 자체검증 N/6 통과`
2. 핵심 카테고리 탐지 4~6건 (before → after)
3. 변경 하이라이트 1~3건 (before → after, 각 100자 이내)
4. 등급 C 이하면 "강도 적극으로 재실행하거나 문단을 나눠 정밀 처리 가능" 안내

## 등급 기준 (자가 채점)

- **A**: S1 잔존 0, S2 잔존 2 이하, 변경률 10~25%, 자체검증 6항 통과
- **B**: S1 잔존 0, S2 잔존 4 이하, 자체검증 5항 이상 통과
- **C**: S1 잔존 1~2 또는 자체검증 4항 이하 통과 — 강도 적극 권고
- **D**: S1 잔존 3+ 또는 변경률 50% 초과 — 작업 중단 권고

## 후속 명령

| 사용자 신호 | 처리 |
|---|---|
| "특정 카테고리만 다시" | 해당 카테고리 finding만 단계 3 재실행 |
| "이 문단만" | 해당 문단만 입력으로 단계 1~5 재실행 |
| "2차 윤문" | 직전 윤문본을 새 입력으로 단계 1~5 재실행 |
| "윤문 강도 조정" | 강도 옵션 변경 후 단계 2부터 재실행 |
| "장르 바꿔서" | 장르 변경 후 단계 2부터 재실행 |

## 엣지 케이스

- **이미 사람이 쓴 글**: 탐지 매치가 거의 없으면 변경률 5% 미만 + 요약에 "윤문 불필요 가능성" 메모.
- **변경률 50% 초과**: 마지막 안전 버전으로 롤백 후 출력, 요약에 `over_polish_aborted: true` 기록.

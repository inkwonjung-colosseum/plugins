## 11. 이해관계자

### 11.1 Power × Interest 그리드

| 영향력 \ 관심도 | 높음 (High Interest — Manage closely / Keep informed) | 낮음 (Low Interest — Keep satisfied / Monitor) |
|---|---|---|
| 높음 (High Power) | - | - |
| 낮음 (Low Power) | - | - |

각 데이터 셀에 이해관계자(또는 조직) 식별자(개인명 또는 조직명)를 채운다. 비어 있으면 `-`. Power × Interest 프레임 힌트(`Manage closely`, `Keep satisfied`, `Keep informed`, `Monitor`)는 컬럼 헤더에서만 사용하며 데이터 셀의 식별자로 인정되지 않는다. 모든 데이터 셀이 `-`이거나 식별자가 1개 미만이면 F11 finding.

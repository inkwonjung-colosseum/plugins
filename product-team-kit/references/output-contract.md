# Output Contract

`plan-draft`와 `plan-format`의 사용자 출력 단일 기준이다. 각 스킬은 판정 결과를 확정한 뒤 아래 템플릿 중 하나를 사용한다.

## 공통 규칙

- 저장 보류, 질문 필요, 사용자 결정 필요, 저장 실패 출력에는 사용자가 바로 복사해 재실행할 수 있는 입력 블록을 포함한다.
- `일반 대화 질문 진행`은 현재 대화에서 바로 답변을 받는 흐름이므로 복사 가능한 재실행 블록을 넣지 않는다.
- 0개 섹션은 통째로 생략한다. `없음`이나 빈 헤더를 출력하지 않는다.
- marker 의미와 화면 출력 합산 기준은 `markers-contract.md`를 따른다.
- 재실행 상태와 terminal hold는 `rerun-contract.md`를 따른다.
- 저장 실패는 추가 기획 질문으로 돌리지 않고 저장 환경 또는 partial artifact 확인으로 안내한다.

## plan-draft

### 기획초안 저장 완료

```text
기획초안 저장 완료
- 추출 기능명: [추출기능명]
- 안전기능명: [안전기능명]
- 초안 생성 가능: 예
- 저장 경로: [실제 생성 경로]
- 로컬 프로젝트 확인: [예/아니오]
- 재실행 맥락: [예/아니오]

[미정] 항목:
- [항목]: [이유] / 결정 주체: [주체 또는 미정]

확인 필요 질문:
- [질문]: [결정 필요 이유] / 결정 주체: [주체 또는 미정]

[충돌 후보]:
- [항목]: 사용자 주장 [내용] / 로컬 근거: [파일경로, section/path, status signal] / 후속 확인 방법: [질문 또는 plan-review 확인]

다음 단계:
- Claude Code: /product-team-kit:plan-format [실제 생성 경로]
- Codex: $plan-format [실제 생성 경로]
```

0개 섹션(`[미정] 항목`, `확인 필요 질문`, `[충돌 후보]`)은 통째로 생략한다. 이 생략 규칙은 화면 출력에만 적용하며, 저장된 기획초안의 필수 섹션 9/10은 생략하지 않는다.

```text
- 이유: 대화형 기획초안을 만들기 부족함

- Codex: $plan-draft
```

### 일반 대화 질문 진행

```text
plan-draft 일반 대화 질문
- 추출 기능명: [추출기능명 또는 기획초안]
- 초안 생성 가능: 아니오
- 파일 생성: 아니오
- 이유: 질문 도구는 없지만 현재 대화를 이어갈 수 있어 일반 대화 fallback으로 질문함
- 질문 라운드: [N]/3
- 로컬 프로젝트 확인: [예/아니오]

필요한 답변:
1. [질문]
2. [질문]
3. [질문]

다음 단계:
답변을 받으면 같은 plan-draft 흐름으로 이어서 판단한다.
```

이 출력은 저장 보류나 terminal hold가 아니다. 현재 응답에서는 파일을 만들지 않으며, 답변을 받은 뒤 저장 가능 조건을 다시 판정한다. 0개 질문이면 이 템플릿을 쓰지 않는다.

```text
- Claude Code: /product-team-kit:plan-draft
```

## plan-format

### 저장 완료

```text
저장 완료
- 추출 기능명: [추출기능명]
- 안전기능명: [안전기능명]
- 초안 생성 가능: 예
- 문서 상태: 로컬 초안
- 팀 문서 반영 상태: 미반영
- 공식 팀 문서: 아니오
- 저장 경로:
  - [실제 저장 경로]/[안전기능명]_기능설계서.md
  - [실제 저장 경로]/[안전기능명]_정책서.md

[생성 요약]:
- 기능설계서: [주요 반영 범위 1~3개]
- 정책서: [주요 반영 범위 1~3개]

[검토 준비 상태]:
- 상태: [plan-review 필요 / 수동 확인 필요 / 초안 검토 가능]
- 이유: [`[미정]`, `[가정]`, 확인 필요 질문, 원본 문서 피드백 중 남은 항목 기준 1~2줄]

[원본 문서 피드백] (N개):
- [유형]: [원문 기준 발견 문제] -> [정리/후속 확인 제안]

확인 필요 질문 (N개):
- [질문]: [결정 필요 이유]

[미확정·가정 항목] (N개):
| 문서 | 유형 | 섹션 | 내용 |
|------|------|------|------|
| 기능설계서 | [미정] | ... | 확인 필요 |
| 정책서 | [가정] | ... | ... |

다음 단계:
- Claude Code: /product-team-kit:plan-review [실제 저장 경로]/
- Codex: $plan-review [실제 저장 경로]/
```

0개 섹션(`[원본 문서 피드백]`, `확인 필요 질문`, `[미확정·가정 항목]`)은 통째로 생략한다.

`[미정]`, `[가정]`, 확인 필요 질문, 원본 문서 피드백 중 하나라도 있으면 발행 전 `plan-review` 실행을 안내한다.

### 기존 산출물 존재 저장 보류

```text
저장 보류
```

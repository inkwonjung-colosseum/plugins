# Markers Contract

`plan-format`은 확정 사실, 미정, 가정, 확인 필요, 충돌 후보를 섞지 않는다. 이 계약은 Gate First 통과 후 문서 본문을 작성할 때만 적용한다.

## Marker 정의

- `[미정]`: 결정되지 않은 필수 판단. 빈 칸 전부가 아니라 문서 확정에 영향을 주는 결정사항에만 사용한다.
- `[가정]`: 입력 근거로 제한적으로 추론한 내용. 확정 사실처럼 쓰지 않는다.
- `[확인 필요]`: 결정자 답변이나 후속 확인이 필요한 항목. 이유, 결정 주체, 후속 확인 방법을 함께 남긴다.
- `[충돌 후보]`: 입력 내부에서 서로 맞지 않는 표현, 중복 기준, 상충되는 조건을 발견했지만 어느 쪽도 확정할 수 없는 항목.

## 표기 구분

`[확인 필요]`와 `확인 필요 질문`은 다른 표기다.

- `[확인 필요]`: 문서 본문 또는 표 셀에 개별 항목 단위로 붙이는 inline 마커.
- `확인 필요 질문`: 출력 템플릿 섹션 헤더와 산문에서 사용하는 모음 레이블.

## 공통 규칙

- 사용자가 모르면 `[미정]`으로 남긴다.
- 공백, 무응답, `모름`, `정하지 않음`만 있는 답변은 해당 항목을 `[미정]`으로 기록한다.
- `[충돌 후보]`는 확정 사실로 쓰지 않는다. 충돌 항목, 입력 안의 상충 표현, 후속 확인 방법을 남긴다.
- `[충돌 후보]`는 저장 차단 사유가 아니다. Gate First를 충족하면 저장하고 충돌 항목으로 남긴다.
- `plan-format`은 Product Docs SSOT를 검색하거나 검증하지 않는다. Product Docs SSOT와의 충돌 검증은 `plan-review`에서 수행한다.

## `plan-format` 적용

- 단일 패스이며 반복 질문 루프를 만들지 않는다.
- 확인 필요 질문은 결정자 호출 필요 항목으로만 남긴다.
- inline 계약: 결정이 쓰이는 본문 문장 또는 표 셀에 `[미정]`/`[가정]`/`[확인 필요]`/`[충돌 후보]`를 표시하고 최종 문서에서 제거하지 않는다.
- 문서 끝 색인 계약: 해당 문서에 marker가 1건 이상 있으면 최종 문서 끝에 `## 미확정·가정·확인 필요` 섹션을 append하고 같은 항목을 색인으로 재목록화한다.
- 화면 출력 계약: 두 문서 전체 marker를 합산해 출력 형식의 `[미확정·가정 항목]` 또는 `확인 필요 질문` 섹션에 넣는다. 0건이면 섹션을 생략한다.

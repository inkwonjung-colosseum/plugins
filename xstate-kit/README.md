# xstate-kit

> XState v5 expert toolkit: author typed statecharts (compound/parallel/history), test (model-based + actor-level mocking), wire React, persist & rehydrate actors, live-inspect with @statelyai/inspect, and export to 14+ graph/diagram formats (Mermaid, DOT, xyflow, GraphML, and more).

## Skills

- **xstate-machine-author** — Author typed, idiomatic XState v5 statecharts using setup().createMachine() — compound, parallel, and history states, actors, guards, and v4-to-v5 porting. Use when creating, refactoring, or fixing a state machine or modeling a workflow.
- **xstate-test** — Test XState v5 machines: model-based path coverage via createTestModel plus actor-level unit tests with machine.provide() mocking, getSnapshot, waitFor, and fake clocks. Use when the user wants tests, path coverage, or a test plan from a statechart.
- **xstate-react** — Wire an XState v5 machine into React with @xstate/react: useMachine, useSelector, useActor, and createActorContext for shared state. Use when using a machine in a component or sharing machine state across a tree.
- **xstate-persistence** — Persist and rehydrate XState v5 actor state with getPersistedSnapshot and createActor({ snapshot }), including spawned-actor sync and snapshot versioning. Use when saving, resuming, restoring, or migrating a running machine's state across reloads, restarts, or requests.
- **xstate-inspect** — Watch a running XState v5 actor live with @statelyai/inspect (createBrowserInspector + the { inspect } actor option). Use when debugging, observing, or visualizing real-time transitions, events, and context of a running machine.
- **xstate-graph** — Convert an XState v5 machine into a directed graph and export it to any of 14 formats (Mermaid, DOT, d2, Cytoscape, xyflow, ELK, D3, GraphML, GEXF, GML, JGF, Adjacency List, Edge List, TGF), prompting the user to pick — 3 primary options plus free-text for the rest. Use when visualizing, diagramming, or documenting a state machine for any tool.
